# Todoist Clone - A React & Firebase Project

## Summary

This application is a **Todoist clone** built using create-react-app as the foundation. It demonstrates modern React development practices using custom hooks, Context API for state management, Firebase for backend services, and React Testing Library for comprehensive testing.

### Key Technologies

- **React**: Custom Hooks and Context API for state management
- **Firebase**: Backend and real-time database
- **React Testing Library**: For testing React components
- **SCSS**: For styling
- **Create-React-App**: Project scaffolding

### Notable Features

The application includes a **dark mode** feature that can be toggled by clicking the Pizza icon in the top right corner. This is a great example of using React hooks to manage theme state globally across the application.

### Project Purpose

This project serves as an educational resource for developers looking to understand how to build real-world applications with React. It goes beyond simple tutorials by implementing a complete, functional application that covers custom hooks, context management, external API integration, and testing strategies.
